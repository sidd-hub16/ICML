Working Principle:

This project uses sensors such as an accelerometer and gyroscope to continuously monitor vehicle movements and detect sudden impacts or abnormal motion.

The collected sensor data is analyzed using predefined thresholds and a machine learning model to identify possible accidents and estimate their severity.

When an accident is detected, the system displays the status on an LCD, provides a local indication, and sends an emergency SMS notification to the registered contact.

An IoT-based dashboard can also display the sensor readings and accident status for remote monitoring, helping to reduce emergency response time.
